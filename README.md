# 神龙消消乐

手机与电脑浏览器中的动物合成试玩，当前版本 **M2 无限畅玩**。

[直接游玩](https://guanzigong-agent.github.io/dragon-merge/)。后续更新继续使用这一主链接。

## 游玩

左右拖动选择落点，松手投放；同类动物接触后合成下一级。电脑也可以使用左右方向键和空格，`P` 暂停。

支持11级合成链、无限体力、三种无限道具、暂停、重新开始和龙神珠之后继续投放。道具包括移除一只、换下一只和摇一摇；超线后可清理顶部，保留积分续玩。

## 版本范围

M2 界面和道具操作已获确认，碰撞和得分仍使用演示参数。排行榜已接入 Cloudflare Worker + D1，朋友只需填昵称即可提交并查看共享最高分。音效和整局游戏存档尚未接入。

直接用浏览器打开 `index.html` 即可运行，无须安装依赖。部署到 GitHub Pages 时，使用 `main` 分支的根目录。

## 其他入口

[M2 独立入口](https://guanzigong-agent.github.io/dragon-merge/m2/)继续保留，也可使用主链接游玩同一版本。[M1-R2 历史试玩](https://guanzigong-agent.github.io/dragon-merge/index-m1-r2.html)保留用于对照。

排行榜保留每个玩家的最高分，刷新后可从云端读取。本浏览器自动记住匿名身份；换设备或清除浏览器数据后须使用新昵称，已使用的昵称不能被另一浏览器覆盖。积分来自客户端，适合朋友试玩，未实现防作弊。

共享服务、数据及部署见 [服务说明](server/README.md)。部分网络对 Cloudflare 默认域名存在解析或连接问题；若榜单无法连接，可稍后重试或换用能够访问该域名的网络，游戏仍可继续。
