# 神龙消消乐

手机与电脑浏览器中的动物合成试玩，当前版本 **M1-R2**。

## 游玩

左右拖动选择落点，松手投放；同类动物接触后合成下一级。电脑也可以使用左右方向键和空格，`P` 暂停。

支持11级合成链、暂停、重新开始、超线提示和龙神珠之后继续投放。图鉴中的动物可以点击查看合成演示。

## 版本范围

这是已通过首轮界面评审的试玩原型。碰撞、得分和体力使用演示参数；原版道具、音效、存档和排行榜尚未实现。

直接用浏览器打开 `index.html` 即可运行，无须安装依赖。部署到 GitHub Pages 时，使用 `main` 分支的根目录。

## M2 独立预览

[试玩无限畅玩预览](https://guanzigong-agent.github.io/dragon-merge/m2/)：无限体力，移除一只、换下一只、摇一摇三种无限道具，以及超线后清理顶部续玩。道具效果为本轮界面提案。

排行榜采用明确标注的示例数据，支持昵称与模拟提交，每个昵称保留本页最高分。数据仅存于当前页面内存，刷新重置，尚未接入跨设备共享后端。本轮界面等待评审，主入口仍为 M1-R2。

本项目没有为参考图片提供新的开放许可，也没有附带原游戏源代码。发布内容仅包含当前试玩所需的前端与参考图片。
